# 에이전트 대화 미리보기

## 배경

기록 화면의 행에는 제목과 프로젝트, 브랜치만 있어서, 아카이브된 에이전트가 무슨 작업을 했는지 보려면 에이전트를 열어야 한다. 열면 기록 화면을 떠나므로 여러 개를 훑어보기 어렵다. 기록 화면을 떠나지 않고 최근 대화를 볼 수 있게 한다.

## 범위

포함

- 행을 누르면 그 행 아래에 최근 대화(사용자 메시지와 어시스턴트 메시지)를 펼친다.
- 펼친 미리보기 안에서 에이전트를 여는 「복원」(아카이브된 행) 또는 「열기」(활성 행) 버튼.

제외

- 마크다운 렌더링. 메시지는 일반 글자로 보여준다.
- 도구 호출, 추론, todo의 내용. 개수만 보여준다.
- 첫 질문 따로 보여주기. 아래 「데이터」 참고.
- 미리보기 안에서 검색, 미리보기 내용으로 목록 거르기.
- 마우스를 올리기만 해도 미리보기 띄우기.
- 아카이브만 해제하고 화면은 그대로 두기. `PaseoApi`에 아카이브 해제 메서드가 없다. 「복원」은 `navigation.openAgent`로 에이전트를 연다.

## 데이터

- `paseo.agents.ref(agentId).timeline.refetch({ direction: "tail", limit: 200, projection: "projected" })`로 마지막 200개 항목을 받는다. 서버 엔트리와 플러그인 RPC는 쓰지 않는다.
- 미리보기를 열 때 그 에이전트 하나만 받는다. React Query 키는 `["agents", "timeline", agentId]`이고 `staleTime`은 목록과 같은 30초다. 같은 에이전트를 다시 열면 캐시를 쓴다.
- 항목은 `entries[].item`이고 종류는 `user_message`·`assistant_message`(`text`), `reasoning`, `tool_call`, `todo`, `error`, `notification` 등이다.
- 2026-11-02 실측(아카이브 587개):
  - 받는 시간은 표본 60개 기준 중앙값 25ms, 90%가 154ms 이하, 최대 502ms다. 응답 크기는 중앙값 4KB, 최대 404KB다.
  - 마지막 200개 항목 안의 사용자·어시스턴트 메시지는 중앙값 12개, 90%가 33개 이하다. 그래서 200개면 보통 대화 전체가 들어온다. `limit: 500`도 거절되지 않았고, 가장 큰 표본은 233개였다.
  - antigravity를 뺀 582개 중 294개는 오류 없이 빈 목록이 왔다. 빈 쪽은 거의 2026-10-02 이전에 만든 에이전트다(빈 목록 중 10-02 이후 생성 2개, 내용 있는 쪽 중 10-02 이전 생성 8개). 데몬에 대화가 저장되지 않은 것으로 보이며, 원인은 확인하지 않았다.
  - antigravity 에이전트는 데몬이 `/opt/homebrew/bin/agy`를 실행하려다 실패해 `refetch`가 `spawn /opt/homebrew/bin/agy ENOENT` 예외를 던졌고, 4.3초 걸렸다. 프로바이더에 따라 타임라인을 받을 때 프로세스를 띄울 수 있다는 뜻이라, 미리보기는 사용자가 누를 때만 받는다.
  - 받은 뒤에도 `archivedAt`은 그대로였다.
- 첫 질문은 `tail`로 받은 범위에 없을 수 있다. 데몬에는 `agent.timeline.list_prompts.request`가 있지만 플러그인 SDK(`PaseoApi`)에는 부르는 메서드가 없고, `direction: "after"`를 커서 없이 보내면 0개가 온다. 그래서 이번에는 넣지 않는다.

## 화면 구성

- 넓은 화면과 좁은 화면 모두 같은 구조다. 행을 누르면 그 행 바로 아래에 미리보기가 펼쳐지고, 다시 누르면 접힌다. 한 번에 하나만 펼친다.
- 펼친 행은 배경을 미리보기와 같은 색으로 둬서 한 덩어리로 보이게 한다.
- 미리보기 내용
  - 첫 줄: 왼쪽에 `메시지 N개 · 생략 M개`(사용자·어시스턴트 메시지가 아닌 항목 수), `hasOlder`가 참이면 `· 이전 대화는 에이전트를 열어서 보기`를 잇는다. 오른쪽에 「복원」 또는 「열기」 버튼(`navigation`이 없으면 숨김).
  - 본문: 사용자·어시스턴트 메시지를 시간순으로 놓고, 높이는 360까지만 쓰고 안에서 스크롤한다. 열면 맨 아래(가장 최근)로 스크롤한다. 사용자 메시지는 배경색으로 구분한다.
  - 빈 목록: 「저장된 대화가 없습니다.」
  - 요청이 예외를 던지거나 응답에 `error`가 있으면: 「미리보기를 불러오지 못했습니다: 오류 문구」. 자동으로 다시 시도하지 않는다.
  - 받는 중: `LoadingText`.
- 간격과 버튼은 기존 스펙처럼 `paseo-ui-kit`의 `SPACE`, `Button`을 쓴다.

## 단축키

웹(데스크톱)에서만 동작한다.

- 행에서 Enter는 클릭과 같아서 미리보기를 펼치거나 접는다. 펼친 뒤 Tab을 누르면 「복원」·「열기」 버튼으로 간다.
- 나머지 단축키는 기존 스펙(`에이전트-기록-필터-2026-10-28.md`)과 같다.

## 결정

- 2026-11-02 사용자 확인: 넓은 화면에서는 목록 오른쪽 칸에 보여준다.
- 2026-11-02 사용자 요청: 오른쪽 칸 대신 행을 누르면 아래로 펼치는 구조로 바꾸고, 에이전트를 여는 「복원」 버튼을 따로 둔다. 그래서 행 클릭과 Enter는 더 이상 에이전트를 열지 않는다.
- 「복원」 버튼은 행이 아니라 펼친 미리보기 안에 둔다. 행 안에 두면 버튼이 Tab 순서에 들어가 「Tab은 목록을 한 번에 건너뛴다」 규칙이 깨지고, `webKeyDown`은 수정 키를 넘겨주지 않아 ⌘Enter 같은 행 단축키도 만들 수 없다. 미리보기 안에 두면 펼친 행에서 Tab 한 번으로 닿는다.
- 미리보기는 아카이브된 행에만 두지 않고 모든 행에 둔다. 받는 방법이 같고, 활성 에이전트만 막을 이유가 없다. 버튼 이름만 활성 행에서는 「열기」로 바꾼다.
- 받는 범위는 항목 200개로 정한다. 실측상 대부분 대화 전체가 들어오고, 최대 응답도 404KB라 한 번 받기에 부담이 없다.
