# 백그라운드 에이전트 표시

## 배경

Paseo 0.16부터 에이전트나 플러그인이 `background: true`로 보조 에이전트를 만들 수 있다. 이 에이전트는 탭을 열지 않고 알림을 보내지 않으며, 사이드바와 기본 에이전트 목록에서 빠진다([#8683](https://github.com/getpaseo/paseo/pull/8683)).

기록 화면은 `paseo.agents.list`를 `includeArchived: true`로만 불러서, 백그라운드 에이전트는 아카이브 여부와 상관없이 기록에 나오지 않는다. 다른 화면에서도 보이지 않는 에이전트라서 기록에서까지 빠지면 찾을 곳이 없다.

## 데이터

- 목록 요청의 `filter.includeBackground`를 `true`로 주면 백그라운드 에이전트도 온다.
- 에이전트 스냅샷의 `background`가 `true`이면 백그라운드 에이전트다.
- 2026-11-20 실측: 이 데몬의 에이전트 841개 중 백그라운드 에이전트는 0개였다. 그래서 전후 비교는 시험용 백그라운드 에이전트를 하나 만들어 확인한다.

## 동작

- 기록 화면은 백그라운드 에이전트도 함께 받는다. 기본 필터는 바꾸지 않는다.
- 출처 필터에 「백그라운드」를 추가한다. 백그라운드 에이전트는 스케줄이나 부모 라벨이 있어도 「백그라운드」로 분류한다. 다른 화면에서 보이지 않는다는 점이 이 에이전트를 찾을 때 가장 중요한 구분이기 때문이다.
- 「판단 대기」 화면은 이번에 바꾸지 않는다.

## 완료 기준

2026-11-20 실측은 프롬프트 없이 만든 시험용 백그라운드 에이전트 1개를 넣고, 변경 전(HEAD)과 변경 후의 `fetchAll`·`filterSections`·`applyFilters`를 같은 데몬 데이터로 돌려 비교했다. 시험용 에이전트와 워크스페이스는 확인 뒤 아카이브했다.

- [x] 백그라운드 에이전트가 기록 목록에 나온다. 실측: 원본 응답 842개(백그라운드 1개) 중 변경 전 841개, 변경 후 842개.
- [x] 출처 필터에서 「백그라운드」를 고르면 백그라운드 에이전트만 남는다. 실측: 결과가 시험용 에이전트 1개.
- [x] 백그라운드가 아닌 에이전트의 출처 분류는 바뀌지 않는다. 실측: 841개 모두 같은 출처, 직접 만듦 767·스케줄 실행 59·하위 에이전트 15.
- [x] `npm run typecheck` 통과, reload 후 `running`(2026-11-20). 화면 확인은 아직이다.
