# 워크스페이스 제목 표시

## 배경

작업은 세션보다 워크스페이스 단위로 나눌 때가 많다. 워크스페이스 제목은 작업 이름으로 직접 지어 두지만, 세션 제목은 첫 메시지에서 자동으로 만들어져 작업 이름과 다른 경우가 많다(예: 워크스페이스 「로그인 오류 문구 수정」 안의 세션 「이 에러 왜 나는지 봐줄래?」).

지금 행의 둘째 줄은 「브랜치, 없으면 워크스페이스 이름」이라서, worktree처럼 브랜치가 있는 워크스페이스에서는 워크스페이스 제목이 화면에 나오지 않는다. 검색은 이미 워크스페이스 제목으로도 걸린다(`searchText`에 `project.workspaceName`이 들어 있다).

## 데이터

- `paseo.agents.list` 항목의 `project.workspaceName`이 워크스페이스 제목이다. 이름을 바꾸면 바뀐 제목이 오고, 아카이브된 에이전트에도 값이 있다(2026-11-13 실측: 최근 40개 모두 값이 있었다).
- 브랜치는 `project.checkout.currentBranch`이고, 워크스페이스 제목과 따로 둔다.

## 화면 구성

- 첫 줄 제목: 워크스페이스 제목. 없으면 세션 제목, 둘 다 없으면 `제목 없음`.
- 둘째 줄: `상태 · 세션 제목 · 프로젝트 · 브랜치 · 프로바이더 · 아카이브`. 세션 제목은 첫 줄에 쓴 값과 같거나 없으면 뺀다. 브랜치는 있으면 늘 보인다.
- 「판단 대기」 화면의 행도 첫 줄 규칙이 같고, 둘째 줄의 위치 줄은 `세션 제목 · 프로젝트 · 브랜치`다.
- 「제목순」 정렬은 첫 줄에 보이는 제목을 기준으로 한다. 실측: 정렬 결과가 `displayTitle` 순서와 일치했다.
- 검색창 안내 문구에 「워크스페이스」를 넣는다. 검색 대상은 바꾸지 않는다.

## 완료 기준

- [ ] 브랜치가 있는 워크스페이스의 행에서 첫 줄에 워크스페이스 제목, 둘째 줄에 세션 제목과 브랜치가 함께 보인다. 2026-11-13 실측: 데몬 데이터로 `displayTitle`·`sessionTitle`·`branch` 값 확인. 화면 확인은 아직이다.
- [x] 워크스페이스 제목과 세션 제목이 같은 행은 둘째 줄에 세션 제목이 반복되지 않는다. 실측: 같은 행의 `sessionTitle`이 `null`.
- [x] 워크스페이스 제목의 일부로 검색하면 그 워크스페이스의 세션이 모두 걸린다. 실측: 에이전트 776개 모두 워크스페이스 제목이 있었고, 제목 앞 6글자 검색 결과가 원본 응답으로 따로 센 건수와 같았다.
- [ ] 「판단 대기」 화면의 행도 같은 규칙으로 보인다.
- [ ] `npm run typecheck` 통과(완료), reload 후 `running`.
