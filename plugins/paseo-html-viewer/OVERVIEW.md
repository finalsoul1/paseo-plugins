Paseo 파일 탭에서 HTML 파일을 렌더링하고 문서 안의 글자를 찾을 수 있게 하는 파일 패널이다. Paseo 내장 HTML 뷰어에는 찾기 기능이 없어서 만들었다.

`.html`·`.htm` 파일을 열 때 나오는 「Open .html files with」 선택 화면에서 「HTML (검색)」을 고른다. 「Always use for .html」을 켜면 다음부터 바로 이 패널로 열린다. 내장 뷰어는 그대로 남는다.

패널을 쓰는 중에 ⌘F(Windows·Linux는 Ctrl+F)를 누르면 오른쪽 위에 찾기 바가 열린다. 입력하는 즉시 대소문자 구분 없이 찾고, Enter와 Shift+Enter로 다음·이전 결과로 이동한다. 찾기 바에 현재 위치와 전체 개수가 보이고, Esc로 닫는다. 굵은 글씨처럼 인라인 요소에 걸친 글자는 찾고, 문단을 넘는 글자와 화면에 보이지 않는 글자는 찾지 않는다. 파일이 바뀌면 다시 렌더링하고 열려 있던 검색어로 다시 찾는다.

문서는 내장 뷰어와 같은 보안 정책으로 렌더링한다. 문서의 스크립트는 실행되지만 네트워크 요청과 외부 이미지·글꼴은 막히고, Paseo 앱에는 접근할 수 없다. 모바일 앱에서는 찾기 없이 문서만 보여 준다.
